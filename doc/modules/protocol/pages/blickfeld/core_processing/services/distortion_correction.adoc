[#Enable]
== Enable

Enable the distortion correction. If available, the user configuration will be taken, otherwise the factory configuration will be 
used. 
 
NOTE: Enabling the distortion correction is persistent, meaning it will still be enabled after reboot and after a factory reset.

[#Disable]
== Disable

Disable the distortion correction. 
 
NOTE: Disabling the distortion correction is persistent, meaning it will still be disabled after reboot and after a factory reset.

[#Status]
== Status

Whether the distortion correction is enabled, and whether a valid configuration is available to apply.
