= Service: Camera

CAUTION: This API is not yet officially released nor maintained.

Service for finding cameras and aiming the ones that can be aimed. 
 
Complements the `DataSource` service, which stores the configuration a camera is described by, 
and the `percept_processing` `Camera` service, which serves what a camera sees.

[#Probe]
== Probe

Identify what answers at an address, before a camera is added to the data source. 
 
This is what lets a client offer to add a camera for an address the user typed, without the 
camera having been configured first. A camera the data source already holds is named by its 
`serial_number` and probed with the credentials stored for it. Fails with `UNAUTHENTICATED` if the device requires 
credentials that were not supplied, so a caller can probe anonymously and only ask the user 
for credentials when the device actually demands them. Fails with `FAILED_PRECONDITION` if 
the camera offers no encoder to stream from besides the one it records with, which is left 
to whatever else records it.

[#PtzControl]
== PtzControl

Drive one camera by hand, for as long as the stream is open. 
 
Automatic tracking is held off that camera while the stream lives and takes it back when the 
stream ends, however it ends - the caller closing it, the page it was opened from being 
reloaded, or the connection dropping. That is the point of aiming by hand being a stream 
rather than a call: a camera cannot be left paused by a client that went away, which is 
exactly what a flag somebody has to remember to clear does. 
 
The first message names the camera and may carry no command, which takes it over without 
moving it. Every message after that is one thing to do with it; each is answered, in order, 
so a caller can tell a command the camera refused from one it has not finished yet. Where 
the camera is while it is being driven is reported by the `Health` service.

[#_blickfeld_percept_pipeline_services_CameraPtzControlRequest_CenterOn]
==== Center On

Bring a point of the camera's own picture to the centre of it. 
 
The offset is a fraction of the frame, so nothing needs to know the camera's field of view, 
and it therefore holds at any zoom.

.Available fields in blickfeld.percept_pipeline.services.CameraPtzControlRequest.CenterOn
|===
| Field | Type | Default | Unit

.2+| *x* | float| - | - 
3+| Where in the picture the point is, as a fraction of the frame from its centre: -0.5 is the 
left edge, +0.5 the right.

.2+| *y* | float| - | - 
3+| The same down the frame: -0.5 is the top edge, +0.5 the bottom.

|===

[#_blickfeld_percept_pipeline_services_CameraPtzControlRequest_ZoomTo]
==== Zoom To

Bring a rectangle of the camera's own picture to the centre of it, and zoom until it fills 
the frame. 
 
The rectangle is in the same fractions of the frame `CenterOn` takes, so nothing needs to 
know the camera's field of view to ask for it. Working out the zoom does need to know how 
that camera's zoom axis maps to focal length; where its `ptz.calibration` does not say, the 
device measures it off the camera once and remembers it for as long as the session lives.

.Available fields in blickfeld.percept_pipeline.services.CameraPtzControlRequest.ZoomTo
|===
| Field | Type | Default | Unit

.2+| *x* | float| - | - 
3+| Centre of the rectangle across the frame, from its centre: -0.5 is the left edge, +0.5 the 
right.

.2+| *y* | float| - | - 
3+| Centre of the rectangle down the frame, from its centre: -0.5 is the top edge, +0.5 the 
bottom.

.2+| *width* | float| - | - 
3+| Width of the rectangle as a fraction of the frame's width. 
 
Widening the frame is as valid as narrowing it: a rectangle larger than the frame zooms out.

.2+| *height* | float| - | - 
3+| Height of the rectangle as a fraction of the frame's height. Whichever of the two needs the 
smaller zoom is the one that fits, so the whole rectangle ends up inside the frame.

|===

[#_blickfeld_percept_pipeline_services_CameraPtzControlResponse]
=== Response Stream

What became of one command on a `PtzControl` stream, in the order they were sent.

.Available fields in blickfeld.percept_pipeline.services.CameraPtzControlResponse
|===
| Field | Type | Default | Unit

.2+| *accepted* | bool| - | - 
3+| Whether the camera took it. A camera that is not connected, or one that refused the move, 
answers false rather than failing the stream - the next command may well work, and a caller 
aiming on somebody's behalf needs to be able to say so without starting again.

.2+| *reason* | string| - | - 
3+| Why it did not, where it did not. Empty otherwise.

.2+| *position* | optional xref:blickfeld/percept_pipeline/config/data_source.adoc#_blickfeld_percept_pipeline_config_DataSource_Camera_Ptz_Position[config.DataSource.Camera.Ptz.Position] | - | - 
3+| Where the head came to rest, for a camera that can be aimed. 
 
Answered once the camera reports itself still, so it is where the command actually ended 
rather than where it was passing through - which is what makes a measurement off a sequence 
of commands possible. Left unset for a camera that cannot be aimed, and for one that never 
reports itself still, where waiting longer would only hold the stream up.
