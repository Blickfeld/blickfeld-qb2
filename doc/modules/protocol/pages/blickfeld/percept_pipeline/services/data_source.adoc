= Service: Data Source

NOTE: This API is officially released and maintained.

The data source service allows getting, configuring and receiving updates of the data source used for processing pipelines. 
The data source configuration specifies where to retrieve the point cloud data for further processing.

[#Register]
== Register

Refines the poses of a set of lidars against each other and levels the fused ground plane on z = 0. 
 
The point clouds are fetched from the lidars themselves, so only their definitions travel with the request. 
The refined poses are returned and not stored: applying them is a separate decision, because anything already 
placed in the map frame moves with it.

[#_blickfeld_percept_pipeline_services_DataSourceRegisterRequest]
=== Request

Request for refining a set of lidar poses

.Available fields in blickfeld.percept_pipeline.services.DataSourceRegisterRequest

.2+| *lidars* | repeated xref:blickfeld/percept_pipeline/config/data_source.adoc#_blickfeld_percept_pipeline_config_DataSource_Qb2[config.DataSource.Qb2] | - | - 
3+| The lidars to register against each other, with the poses to start from. They do not have to be the configured 
ones, so a setup can be registered while it is being put together.

[#Align]
== Align

Estimates the pose that puts a single lidar's point cloud on the ground plane. 
 
The frame and the accelerometer reading are fetched from the lidar, so a lidar that is not part of the 
configuration yet can be aligned while it is being added.

[#_blickfeld_percept_pipeline_services_DataSourceAlignRequest_Strategy]
==== Strategy

How to estimate the ground plane

.Available values for blickfeld.percept_pipeline.services.DataSourceAlignRequest.Strategy enum
[cols='25h,5,~']
|===
| Name | Value | Description

| STRATEGY_UNSPECIFIED ^| 0 | Unspecified. Behaves like STRATEGY_AUTO.
| STRATEGY_AUTO ^| 1 | Uses the plane segmentation when it agrees with the measured gravity, and the accelerometer otherwise.
| STRATEGY_PLANE_SEGMENTATION ^| 2 | Uses the orientation and translation computed from the plane segmentation.
| STRATEGY_ACCELEROMETER ^| 3 | Uses the orientation from the accelerometer.
|===
